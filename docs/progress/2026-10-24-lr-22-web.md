# 2026-10-24 — LR-22 portal half: the RU landing on the portal

## Goal

LR-22 (RU web entry point) for the portal, with the launch plan's section 7 default: the
RU landing is the RU portal's own guest home at `omoba.ru`, hosted in Russia with no
foreign analytics; the omoba.io landing is not changed. Branch `feat/lr-22`, built on the
open LR-06 portal branch (`feat/lr-06-portal`, PR #19), which must merge first. The game
half (Russian package README, RU server bundle) is omoba-bevy `feat/lr-22`.

## Changes

- `src/lib/market-profile.mjs`: `MARKET_LANDING` and the accessor `marketLanding(market)`
  (`home: site | portal`, `workshop: listed | experimental`; RU = portal + experimental).
  `marketProblems` refuses `OMOBA_SITE_URL` where the landing is the portal. No new raw
  market comparison: UI code reads `landing` from the market context.
- `src/lib/navigation.mjs`: `contourSiteUrl` is `/` in such a market (every "OMOBA website"
  link: workshop, legal pages, footer); `mobileNav` leaves an experimental workshop out.
- `src/app/[[...path]]/page.tsx`: `/` in a portal-landing market renders the guest home
  signed out and redirects to `/me` signed in (global keeps `/` → `/workshop`). Its metadata:
  localized title and description, `index, follow` in production only, canonical link and
  `hreflang` = the market's page language.
- `src/lib/landing-server.ts`: the class count from `public/asset-catalog/catalog.json` (the
  game catalog snapshot, verified at build; 17), and the catalog `GET /v1/releases` read on
  the server so the landing lists downloads without JavaScript.
- `src/lib/releases.mjs`: direct downloads only (`channel` direct or absent; Windows, macOS,
  Linux, Android; https URL, SHA-256, size), newest per platform, platform order; sizes in
  МБ/MB; the release status in the page language («Открытая бета» → "Open beta"). IPFS
  mirrors, store channels and iOS packages are never offered.
- `src/components/guest-home.tsx`, `releases.tsx`: the guest home (claims, modes as the game
  names them, status, age sign, downloads, how progress is kept with VK ID) and the shared
  download card (also `/download`, which lists `?platform=` first). The portal shell for a
  portal-landing market: brand → `/`, no external website button, footer `OMOBA` + legal
  links + age sign, the sidebar's workshop tagged «эксперимент»; the workshop page shows an
  experimental notice.
- Strings in en/ru/zh in `src/lib/landing-translations.ts` (Russian plurals for the class
  claim); styles in `globals.css`.
- Tests: `tests/landing.test.mjs` (in `npm test`), `tests/ru-landing.e2e.mjs`
  (`npm run test:ru-landing`), `tests/locale.test.mjs` covers the new components.
- Docs: `docs/markets.md` (RU landing section, age sign row, verification), `README.md`
  (`OMOBA_SITE_URL`), `docs/TESTING.md`.
